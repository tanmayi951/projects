# YouTube Focus Board

## Install in Chrome
1. Open `chrome://extensions` and turn on **Developer mode**.
2. Choose **Load unpacked** and select this `youtube-focus` folder.
3. Visit YouTube. Click the extension icon to configure distraction switches, add videos and save timestamp notes.

Data is stored with Chrome's local extension storage. The focus gate requires a study intention and opens a 60-minute window. Timestamp notes open at their saved time.
