# Job Clipper

## Install in Chrome
1. Open `chrome://extensions` and turn on **Developer mode**.
2. Choose **Load unpacked** and select this `job-clipper` folder.
3. Open a job page and click the extension icon. Edit detected details and save. Use **Open board** to search, drag applications between stages, add deadlines, edit details, or export CSV.

Chrome asks for site access so the extension can read the active job page. Job data stays in `chrome.storage.local`. Deadline alerts use Chrome notifications and fire the day before the deadline.
