# Job Clipper · Prompt log

1 Build a Manifest V3 extension that reads the current page title and URL, attempts to detect company details, and lets the user edit role, company, URL and deadline before saving.
2 Add a searchable application board with Saved, Applied, Interview and Result columns. Support drag and drop, manual editing, deletion and CSV export.
3 Store jobs locally and schedule a Chrome notification for the day before each deadline. Include an unpacked extension guide and manual entry for pages that cannot be parsed.
