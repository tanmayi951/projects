# Same Page, New Design

Open `before.html` and `after.html` to compare the same Northstar Fest page copy. The redesign applies the local design checklist in `design-skill.md`; the page adapts to phone widths. Three design changes: a stronger event/date/action hierarchy helps visitors orient quickly; the event details are grouped into scannable cards; and the warm illustration and single orange action create an event identity while keeping the registration link prominent.
