# Design Skill Applied · Event landing pages

Use the following checklist when redesigning a simple event page. Preserve all copy exactly. First identify audience, main action, and content hierarchy; then improve the visual system around those needs.

- Give the event name clear visual priority, followed by the date and one primary action.
- Keep body copy readable and line lengths short.
- Use one memorable visual that supports the event mood without competing with the registration action.
- Present secondary information as scannable cards with consistent spacing and labels.
- Choose a compact palette with one strong action color and check text contrast.
- Make the layout collapse to a single column on narrow screens, with a large tappable action.
- Explain each major design decision in terms of the user's task, readability, or orientation.
