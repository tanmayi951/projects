# Viva Practice Skill

This is a reusable Codex-style skill package. To install it locally, copy the folder to your personal skills directory as `viva-practice`, then start a fresh conversation and ask to practise a viva from your notes. The skill only uses notes you provide; the sample below is fake classroom material.

## Sample input

> Practise a 5-question viva from sample-notes.md. Ask one question at a time.

## Sample notes

The Carnot cycle is a theoretical reversible cycle operating between a hot reservoir and a cold reservoir. Its efficiency is the maximum possible efficiency for any engine operating between those two temperatures. Real engines have lower efficiency because of irreversibilities such as friction and heat transfer across a finite temperature difference. The second law rules out converting all absorbed heat into work in a cyclic engine.
